## Проверки версии 1.2

- После импорта ноября с двумя сменами (17 рабочих часов) импортирован декабрь с одной сменой (7 часов). На телефоне остались все три смены; стрелка предыдущего месяца открыла ноябрь с исходным итогом и отметкой «Архив».
- После остановки процесса и запуска без Wi-Fi и мобильной сети ноябрь и его итог остались доступны.
- Файл старого формата без метаданных истории прочитан без потери смен. После загрузки декабря, сохранения и перезапуска сохранились ноябрь, ручные правки и месячные итоги.
- Пустой CSV не удаляет сохранённые месяцы. Повторная загрузка месяца обновляет его целиком и удаляет пропущенные исходные смены только в этом месяце.
- Полный сброс явно удаляет архив и локальные правки, оставляя только свежий источник.

## Проверки версии 1.1

- Сравнены координаты всех видимых ячеек до и после выбора дня: они не изменились в начале экрана и после прокрутки.
- Жест вниз на календаре запускает настоящую загрузку Google-источника без дополнительного подтверждения.
- Через интерфейс изменена смена, добавлена новая и удалена исходная. После обновления жестом все три локальные правки сохранились без изменений.
- Полный сброс при отключённых Wi-Fi и мобильной сети оставил сохранённый JSON неизменным.
- Успешный полный сброс удалил локальные правки; исходные смены совпали с независимым свежим CSV-экспортом Google-таблицы. Во время проверки таблица редактировалась владельцем, поэтому результат сверялся с актуальными значениями, а не с прежним итогом.
- Выбор тёмной темы сохранился после перезапуска процесса и полного сброса графика. Проверены календарь, настройки, диалоги и системные панели.
- Публичная сборка формируется с `-PpublicBuild=true`; личная ссылка и имя берутся только из игнорируемого Git локального файла для персональной сборки.

Физический телефон и остальные версии Android отдельно не проверялись. Минимальная поддерживаемая версия по API и сборке — Android 8.0. Работоспособность Google-источника проверена с текущими правами чтения; если владелец закроет доступ или изменит структуру столбцов, приложение сообщит об ошибке и сохранит локальные данные.
