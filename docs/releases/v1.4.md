# Смена 1.4

- Новая вкладка «Зарплата» между графиком и настройками: примерный заработок за месяц и каждую смену по ставке 324 ₽/час после вычета обедов.
- Поле «Полученный аванс»: полная зарплата и остаток к получению видны отдельно, остаток пересчитывается сразу при вводе.
- Аванс сохраняется автоматически для каждого сотрудника, месяца и года. Поддерживаются рубли и копейки; очистка поля возвращает аванс к нулю.
- Зарплата учитывает ручные правки, правила обедов и архивные месяцы.
- В настройках появилась проверка и установка обновлений с GitHub через стандартный установщик Android.

Расчёт зарплаты примерный. Если аванс больше расчётной суммы, приложение показывает превышение.

Установите APK поверх прежней версии — график, архив и настройки сохранятся.
