# Публикация рабочих версий

Публиковать рабочие версии в GitHub Releases только после явного подтверждения пользователя. Каждый релиз сопровождается патчноутами на русском.

В публичный релиз включаются APK, собранный с `-PpublicBuild=true`, его SHA-256 и `update.json`. Функциональность и подпись совпадают с личной сборкой; встроенные личные настройки в публичную сборку не входят.

Перед публикацией проверить версию APK, контрольную сумму, подпись и отсутствие личных значений. Изменения и файлы `dist/smena-public.apk`, `dist/smena-public.apk.sha256`, `dist/update.json` должны находиться в `main`, чтобы проверка обновлений из приложения видела опубликованную версию.

Создать тег `v<версия>` на проверенном коммите `main`, загрузить файлы в черновик релиза, проверить вложения и затем опубликовать его. Имя установочного файла должно включать номер версии, например `smena-1.4.1.apk`.
